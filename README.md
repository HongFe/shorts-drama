# shorts-drama

1분 안팎의 세로형 채팅 드라마 테스트 시청 페이지입니다.

▶ **보러 가기:** https://hongfe.github.io/shorts-drama/

## 「오발송」 시즌 1 (5화)
결혼 두 달 전, 남친이 보낸 문자 한 통이 나에게 잘못 왔다.

| 화 | 제목 |
|---|---|
| EP.01 | 남친이 보낸 문자, 나한테 온 게 아니었다 |
| EP.02 | 친구가 보낸 사진 속 남자 |
| EP.03 | 3천만 원만 보내 달래요 |
| EP.04 | 같은 시각, 그들의 대화방 |
| EP.05 | 월요일, 본부장이 출근했다 |
